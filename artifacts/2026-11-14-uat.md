# User Acceptance Testing

1. `sns doctor` after login. On a Mac the keychain line should be `ok` and "session key retrieved", and there should be no `.env.keys`.
2. `sns sync` once, then `sns list` and `sns show` on one note.
3. `sns copy <id> <key>`, paste to prove the value arrived, then check the clear.
4. `sns` with no args: View, Copy, Quit.
5. `sns logout`, then `sns login` once.
